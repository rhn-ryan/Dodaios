# Dodaios Knowledge System

This directory contains the persistent engineering intelligence system for the Dodaios codebase.

## Structure

- `README.md` - This file
- `KNOWLEDGE_INDEX.md` - Master index of all knowledge artifacts
- `PROJECT_OVERVIEW.md` - High-level project overview
- `ARCHITECTURE.md` - System architecture documentation
- `RUNTIME_LIFECYCLE.md` - Application runtime lifecycle
- `DATA_ARCHITECTURE.md` - Data models and persistence
- `API_AND_CONTRACTS.md` - API endpoints and interface contracts
- `DEPENDENCY_MAP.md` - Module dependency relationships
- `TESTING_MAP.md` - Test coverage and failure intelligence
- `EXTENSION_GUIDE.md` - Feature extension guidance
- `KNOWN_ISSUES.md` - Known limitations and issues

- `inventory/` - Repository inventory (files, symbols, dependencies)
- `modules/` - Per-module documentation
- `flows/` - Execution flow documentation
- `graph/` - Machine-readable knowledge graph (JSONL)
- `diagrams/` - Mermaid diagrams
- `decisions/` - Architectural Decision Records (ADRs)
- `changes/` - Knowledge evolution manifests
- `history/` - Historical snapshots
- `validation/` - Validation reports and coverage
- `workspace/` - Operational state and progress tracking

## Source of Truth

The codebase is the source of truth. This knowledge system is its verified architectural representation.
